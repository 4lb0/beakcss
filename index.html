Beak CSS

A classless fork of Pico CSS — no classes, no SASS, just HTML.

npm install beakcss

Themes

There are two kinds, and both are loaded after the base stylesheet — never instead of it.

Tints (dist/themes/blue.css) are about 1.4 KB: they swap the accent ramps only and stay light/dark aware, so they follow the OS. Full palettes (dist/themes/full/dracula.css) are complete schemes — background, text, borders, code, forms, shadows. 

<link rel="stylesheet" href="dist/beak.min.css">
<link rel="stylesheet" href="dist/themes/full/solarized-auto.css">

Full palettes come in three shapes:

  • Adaptive (solarized-auto.css, nord-auto.css, …) — the light flavour fills the light blocks and the dark flavour fills the prefers-color-scheme and [data-theme="dark"] blocks. Auto / Light / Dark keep working. Use these for families that ship both flavours.
  • Dark-only (dracula.css, kanagawa.css, …) and light-only (solarized-light.css) — pinned: the same values in all three blocks, so the scheme never flips with the OS and the toggle buttons become inert.

Body text and links stay at WCAG AA (4.5:1) against each palette's own background. Machine-readable index: llms.txt.
