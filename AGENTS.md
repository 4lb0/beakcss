# AGENTS.md

## llms.txt

`llms.txt` is a usage index for LLMs, not a project page. Keep it short.

- Usage only: what Beak is, files, how to load it, one copy-paste example, themes, house rules.
- No "Start here" bench, doc/changelog link dump or build notes (never mention `tools/*.py`).
- Show a minimal classless HTML page instead of linking the demo.
- Themes: one line per family with `(l)`/`(d)` flavours, auto variants as `x-auto = light/dark`, paths declared once instead of repeated URLs.
- It is generated by `tools/themes.py` (`write_llms`): edit the generator, run `python3 tools/themes.py`, never the file directly.
